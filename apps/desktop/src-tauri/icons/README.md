The Kiln mark: two nested arches with a glow, on a dark tile (the same geometry as `apps/web/public/favicon.svg`).

Every file here is generated by one script. From this folder, with Pillow installed:

    python3 make-icons.py

It writes `source-1024.png`, `icon.png`, `32x32.png`, `128x128.png`, `128x128@2x.png`, `icon.ico` and `icon.icns`.
To use other artwork instead, run `pnpm tauri icon path/to/app-icon.png` from `apps/desktop` on a square PNG of at least 1024x1024.
