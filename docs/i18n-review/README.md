# Native-speaker review sheets

`fr.md`, `es.md` and `de.md` list every message added or changed in the French, Spanish and German catalogs since commit 550fb83, one table per namespace, with a glossary of the recurring product terms at the top. All of it is machine-quality text that no native speaker has reviewed yet. To send corrections, either fill the `OK/Fix` column (write the corrected wording in the notes column) and send the file back, or, preferably, open a pull request that edits the locale JSON directly (`apps/web/locales/<namespace>/<lang>.json`, `apps/server/locales/<namespace>/<lang>.json`; the key in the first column is the JSON key). Keep `{{placeholders}}`, `<link>`/`<strong>` tags and product names (Kiln, App Store Connect, TestFlight, Google Play, RevenueCat, Expo, EAS, Orbit, Apple Ads) exactly as they are, keep the register (fr vous, es tú, de Sie), and run `pnpm i18n:fix && pnpm i18n:check --strict` before pushing. See [../i18n.md](../i18n.md) for the plural forms and the tooling.
