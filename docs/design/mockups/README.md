# Readability mockups (2026-11-20)

Static mockups approved as the direction for the whole app. Open the `.dc.html` files in a design canvas, or read them as plain HTML.

- `stepper-build.dc.html`: Prepare release, Build step (steps in a left rail, one heading, compact choices, Back/Next fixed at the bottom).
- `stepper-confirm.dc.html`: Prepare release, Confirm step (what will be written, in order; one primary action).
- `app-overview.dc.html`: App overview (one "Your next step" card, platforms side by side with their tint, short attention list).
- `publish-dialog.dc.html`: Review and publish dialog (steps, one irreversible acknowledgement, no typed phrase when password or passkey confirms).

Rule for every screen: 1) where am I and what is the ONE next action, 2) the data I must decide on, 3) warnings in one line next to the action, 4) everything else behind Details. See `docs/design/readability.md`.
